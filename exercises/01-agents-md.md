# 1 · AGENTS.md (10 min)

**Ziel:** Eine AGENTS.md erzeugen lassen und verstehen, warum ihre Teile darin stehen.

1. Copilot Chat, Modus **Agent**:
   ```
   /init
   ```
2. Liegt das Ergebnis unter `.github/copilot-instructions.md`, die Datei in den root-Ordner des Projekts verschieben.
3. `AGENTS.md` lesen. Zu jedem Abschnitt überlegen: Warum steht das hier, und was würde Copilot ohne diese Information falsch machen? Bei Unklarheiten Copilot selbst fragen, wofür er einen Abschnitt braucht.

**Merke:** Die AGENTS.md geht bei jeder Anfrage an Copilot mit. Deshalb kurz halten und nur aufnehmen, was für die meisten Aufgaben in diesem Repo wichtig ist.

**Wenn es klemmt**
- `/init` wird nicht erkannt → VS Code und Copilot-Chat-Erweiterung aktualisieren.
